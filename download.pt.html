🍺 Homebrew primeira versão

Fórmula com um bloco de serviço (brew services start nzbfast).

brew install nzbfast/tap/nzbfast
Verificando os downloads: cada versão traz somas sha256 ao lado dos artefatos na página de versões. Os zips do macOS preservam os bits de execução; a primeira abertura limpa o sinalizador de quarentena para você (o script lançador faz isso — é a maior parte do que ele serve).

Dois minutos até o primeiro download

  • 1. Descompacte e execute Start nzbfast (mac: .command, windows: .bat) — ou apenas ./nzbfast setup em um terminal.
  • 2. O assistente encontra uma configuração existente do SABnzbd/NZBGet e se oferece para usá-la; caso contrário, pede o host, o usuário, a senha e a contagem de conexões do seu provedor.
  • 3. O painel abre em http://localhost:6789. Solte um .nzb em qualquer lugar dele — ou aponte o Sonarr/Radarr para ele como cliente SABnzbd.

Atualizar é substituir um arquivo. Ajustes, fila e histórico ficam ao lado da sua configuração e sobrevivem a reinícios e atualizações.

Notas por plataforma

  • Raspberry Pi / NAS ARM — use o build Linux arm64. A decodificação SIMD do motor tem kernels NEON; um Pi 5 satura gigabit com folga.
  • Unraid — instale pelo Community Apps quando o template for publicado (imagem Docker por baixo); até lá, adicione a imagem manualmente.
  • TrueNAS SCALE — rode a imagem Docker como um app personalizado.
  • FreeBSD / outros — espera-se que cargo build --release a partir do código funcione (rustls, sem OpenSSL); oficialmente sem testes. O reparo PAR2 e a extração RAR são nativos em todas as plataformas.
  • Celulares — nada para instalar: o painel tem um layout de celular de primeira classe, e o nzb360/LunaSea conectam pela API compatível com o NZBGet.
