One binary. Batteries included.

Every build is a single self-contained executable — repair (par2) and unpack (unrar) are embedded. Unzip, run the launcher, answer three questions, download.

Verifying downloads: every release ships sha256 sums next to the artifacts on the releases page. macOS zips preserve executable bits; first launch clears the quarantine flag for you (the launcher script does it — that's most of what it's for).

Two minutes to first download

  • 1. Unzip and run Start nzbfast (mac: .command, windows: .bat) — or just ./nzbfast setup in a terminal.
  • 2. The wizard finds an existing SABnzbd/NZBGet config and offers to use it; otherwise it asks for your provider's host, username, password and connection count.
  • 3. The dashboard opens at http://localhost:6789. Drop an .nzb anywhere on it — or point Sonarr/Radarr at it as a SABnzbd client.

Upgrading is replacing one file. Settings, queue and history live next to your config and survive restarts and upgrades.

Platform notes

  • Raspberry Pi / ARM NAS — use the Linux arm64 build. The engine's SIMD decode has NEON kernels; a Pi 5 saturates gigabit with headroom.
  • Unraid — install from Community Apps once the template is published (Docker image underneath); until then, add the image manually.
  • TrueNAS SCALE — run the Docker image as a custom app.
  • FreeBSD / others — cargo build --release from source is expected to work (rustls, no OpenSSL); officially untested. par2/unrar resolve from $PATH on non-mac/windows platforms for now.
  • Phones — nothing to install: the dashboard has a first-class phone layout, and nzb360/LunaSea connect via the NZBGet-compatible API.
