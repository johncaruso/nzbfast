یک باینری. همه‌چیز همراه.

هر بیلد یک فایل اجرایی خودکفای واحد است — تعمیر (par2) و باز کردن (RAR) تعبیه‌شده‌اند. اکسترکت کنید، راه‌انداز را اجرا کنید، به سه سؤال پاسخ دهید، دانلود کنید.

🍎 macOS در دسترس

اپ NzbFast — به Applications بکشید و شروع کنید. یونیورسال (Apple Silicon و Intel)، داشبورد در پنجرهٔ خودش، دوکلیک ‎.nzb، شروع هنگام ورود.

macOS 12+ · ~16 MB DMG · اپ + موتور

دانلود اپ مک ‎.zip قابل حمل

🪟 Windows در دسترس

نصاب یک اپ سینی (بدون پنجرهٔ کنسول)، ورودی منوی Start، شروع-با-Windows اختیاری و دوکلیک ‎.nzb راه‌اندازی می‌کند. کاملاً ایستا — بدون زمان‌اجرا برای نصب؛ می‌تواند پیکربندی موجود SABnzbd شما را هم بپذیرد.

Windows 10/11 x64 · ~8 MB نصاب

دانلود نصاب ‎.zip قابل حمل

🐧 Linux در دسترس

بیلدهای ایستای musl برای x86_64 و arm64 — سیدباکس‌ها، VPSها، هر NAS با SSH، Raspberry Pi 4/5. بدون رولت نسخهٔ glibc.

x86_64 · arm64 · واحد systemd گنجانده شده

x86_64 arm64 بستهٔ NAS

🐳 Docker اولین انتشار

تصویر چند-معماری (amd64 + arm64)، نقطهٔ ورود PUID/PGID به‌سبک linuxserver، بررسی سلامت، فایل compose. این مسیر برای Unraid، TrueNAS SCALE و QNAP Container Station است.

docker run -p 6789:6789 -v ./config:/config \
  -v ./downloads:/downloads nzbfast/nzbfast

📦 Synology برنامه‌ریزی‌شده

‎.spk بومی برای مرکز بستهٔ DSM 7. تا زمان رسیدنش، مدیر کانتینر Synology تصویر Docker را به‌خوبی اجرا می‌کند.

DSM 7 · مدل‌های x86_64 + arm64

🍺 Homebrew اولین انتشار

فرمول با یک بلوک سرویس (brew services start nzbfast).

brew install nzbfast/tap/nzbfast
تأیید دانلودها: هر انتشار جمع‌های sha256 را کنار مصنوعات در صفحهٔ انتشارها عرضه می‌کند. زیپ‌های macOS بیت‌های اجرایی را حفظ می‌کنند؛ اولین اجرا پرچم قرنطینه را برایتان پاک می‌کند (اسکریپت راه‌انداز این کار را می‌کند — بیشتر کارش همین است).

دو دقیقه تا اولین دانلود

  • 1. اکسترکت کنید و Start nzbfast را اجرا کنید (مک: ‎.command، ویندوز: ‎.bat) — یا فقط ./nzbfast setup در یک ترمینال.
  • 2. جادوگر یک پیکربندی موجود SABnzbd/NZBGet را پیدا می‌کند و پیشنهاد استفاده از آن را می‌دهد؛ در غیر این صورت میزبان، نام کاربری، رمز عبور و تعداد اتصال ارائه‌دهندهٔ شما را می‌پرسد.
  • 3. داشبورد در http://localhost:6789 باز می‌شود. یک ‎.nzb را هرجای آن رها کنید — یا Sonarr/Radarr را به‌عنوان یک کلاینت SABnzbd به آن نشانه بگیرید.

ارتقا یعنی جایگزینی یک فایل. تنظیمات، صف و تاریخچه کنار پیکربندی شما زندگی می‌کنند و از راه‌اندازی مجدد و ارتقاها جان به در می‌برند.

یادداشت‌های پلتفرم

  • Raspberry Pi / ARM NAS — از بیلد Linux arm64 استفاده کنید. رمزگشایی SIMD موتور هسته‌های NEON دارد؛ یک Pi 5 گیگابیت را با فضای مانور اشباع می‌کند.
  • Unraid — پس از انتشار قالب از Community Apps نصب کنید (تصویر Docker در زیر)؛ تا آن زمان، تصویر را دستی اضافه کنید.
  • TrueNAS SCALE — تصویر Docker را به‌عنوان یک اپ سفارشی اجرا کنید.
  • FreeBSD / سایر — cargo build --release از منبع انتظار می‌رود کار کند (rustls، بدون OpenSSL)؛ رسماً آزموده نشده. تعمیر PAR2 و باز کردن RAR روی هر پلتفرم بومی‌اند.
  • گوشی‌ها — چیزی برای نصب نیست: داشبورد یک چیدمان گوشی درجه‌یک دارد، و nzb360/LunaSea از طریق API سازگار با NZBGet متصل می‌شوند.
