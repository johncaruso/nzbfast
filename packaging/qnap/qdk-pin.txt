# QDK, QNAP's package build kit, pinned by commit.
#
# The .qpkg format is a self-extracting shell script with a control tar
# and a data tar concatenated onto it, and the installer half - qinstall.sh
# - is COPIED INTO EVERY PACKAGE at build time. So the QDK revision is not
# a build-time detail: it is code that ships to users and runs as root on
# their NAS. Tracking master would silently change that code between one
# release and the next.
#
# Bump deliberately: read the diff of shared/scripts/qinstall.sh and
# shared/bin/qbuild first, then rebuild and re-run
# packaging/tests/qnap-install.sh.
