Five candidates, judged at the size that actually matters

The reported problem is not how the icon looks large, it is that it disappears in a taskbar. So every candidate below is shown at its true 16, 32 and 48 pixel renders, on both a dark and a light taskbar ground, with the 16 pixel version enlarged so you can see what survives. The large tile on the left is the same art at 128 px.

My recommendation

Bolt, refined for 16 and 32 px, the slipstream version for 128 px and above. That split is normal: both Windows .ico and macOS .icns store separate images per size, so the small art can drop detail the large art keeps. Shipping it also means replacing the emoji-data-URI favicon with real PNGs and a manifest, which is why a browser shortcut currently falls back to a generated letter N.
